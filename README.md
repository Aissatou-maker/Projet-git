# Projet Git

## Présentation du projet

Bienvenue dans mon dépôt GitHub **Projet-git**.

Ce projet a pour objectif de découvrir et de pratiquer la gestion de versions avec Git et GitHub.

## Objectifs

- Apprendre à utiliser Git.
- Créer et gérer un dépôt GitHub.
- Ajouter et modifier des fichiers.
- Effectuer des commits.
- Envoyer les modifications locales vers GitHub.

## Technologies utilisées

- Git
- GitHub
- Markdown

## Installation

Pour récupérer ce projet sur votre ordinateur, exécutez :

```bash
git clone https://github.com/Aissatou-maker/Projet-git.git
```

## Commandes Git utilisées

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/Aissatou-maker/Projet-git.git
git push -u origin main
```
